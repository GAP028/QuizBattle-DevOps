# QuizBattle — Projet DevOps

Projet de groupe IPSSI — La Bataille des Services.

## Application

Quiz en direct permettant de répondre à des questions,
de calculer les scores et d'afficher un classement final.

## Équipe

- Alain-Patrick Gomas : livraison CI/CD
- Orokia : état et données
- Adam : mesure et supervision
- Yassine : images Docker

## Architecture prévue

- Front-end : interface du quiz
- API : questions, réponses et scores
- PostgreSQL : stockage des données
- Service annexe : statistiques du quiz

## Technologies

Docker, Docker Compose, GitHub Actions,
Docker Hub, Node.js, PostgreSQL,
Prometheus et Grafana.

## État du projet

Développement en cours.
